# Phase 1 — HLA-B/C strand validation of the exon5_skip / intron5_retention classifier

Generated by `phase1_bc_strand_check.py`. Question: HLA-A's classifier (`analyze_brca.classify_events`) assumes donor=First_base, acceptor=Last_base, geometry written in transcript-5'->3' terms -- correct for plus-strand junctions. HLA-B/C are reverse-strand genes. Does the classifier need a strand-aware fix before it can be trusted on B/C data?

**Empirical basis:** `First_base <= Last_base` holds for every row across A/B/C (0 violations) -- coordinates are stored in genomic left-to-right order, not already re-oriented per transcript. HLA-A is ~97.8% `Strand==1` (plus); HLA-B is ~97.7% `Strand==2` (minus), HLA-C is ~94.4% `Strand==2` (minus). So the large majority of B/C junctions are exactly the case the naive classifier's geometry doesn't cover. `hla_common.classify_events_strand_aware()` implements the fix: for `Strand==2` rows, mirror coordinates (`W1'=-W2, W2'=-W1`, same for V1/V2) before applying the *unchanged* exon5_skip/intron5_retention geometry -- this swaps donor/acceptor roles and reverses "downstream" to match a minus-strand transcript, while leaving plus-strand rows and all of HLA-A's existing behavior untouched.

### HLA-B: **untrustworthy**

too little signal to validate either scheme: only 1 exon5_skip/intron5_retention carriers naive, 0 flipped (out of 2 total candidate AS events across 935+106 samples -- this gene's max observed Local_rate and overall AS-event yield are much lower than A/the other B/C gene; see OVERNIGHT_LOG.md). Insufficient data to tell whether the classifier needs a strand fix for this gene at all.

- 935 tumor / 106 normal samples, 71 distinct alleles, 2 candidate AS events (Local_rate>10%, same filter as A).
- Constitutive-vs-variable check (20+ sample alleles, AS_pattern-based, classifier-independent): 0 allele(s) look like constitutive annotation artifacts (A*11:01-style), 0 look like real variable splicing, 2 too rare to call. Full table: `outputs/table_phase1_penetrance_HLA_B.csv`.
- Classifier comparison detail: `outputs/table_phase1_classifier_comparison_HLA_B.csv` (every event row, naive vs strand-aware label, flagged where they differ).
- Most-recurrent AS_pattern per allele: `outputs/table_phase1_top_patterns_HLA_B.csv`.

### HLA-C: **valid_as_is**

naive (strand-blind) classification finds 30 exon5_skip/intron5_retention carriers with geometrically coherent, A-like patterns (donor-fixed-acceptor-jumps for exon5_skip, acceptor-fixed-donor-shifts for intron5_retention), including a real_variable_splicing_candidate allele (non-artifact, present in some but not all carriers). The strand-aware flip finds only 0 and turns essentially every event into 'other', destroying that signal. Despite 94.7% of rows being Strand==2 (this gene's known minus-strand genomic orientation), this export's First_base/Last_base coordinates behave as already transcript-oriented (same convention as HLA-A) -- Strand appears to record the source gene's genomic strand as metadata, not a required per-row coordinate transform. No flip applied.

- 933 tumor / 106 normal samples, 32 distinct alleles, 60 candidate AS events (Local_rate>10%, same filter as A).
- Constitutive-vs-variable check (20+ sample alleles, AS_pattern-based, classifier-independent): 0 allele(s) look like constitutive annotation artifacts (A*11:01-style), 6 look like real variable splicing, 5 too rare to call. Full table: `outputs/table_phase1_penetrance_HLA_C.csv`.
- Classifier comparison detail: `outputs/table_phase1_classifier_comparison_HLA_C.csv` (every event row, naive vs strand-aware label, flagged where they differ).
- Most-recurrent AS_pattern per allele: `outputs/table_phase1_top_patterns_HLA_C.csv`.

## Quarantine rule applied to later phases

- **HLA-B**: classifier is **untrustworthy** for this gene under either scheme. Per the quarantine rule, HLA-B's tumor-vs-normal exon5_skip/intron5_retention results go to `outputs/UNVALIDATED_HLA_B_*` ONLY, marked 'NOT FOR PRESENTATION -- pending manual strand review', and are excluded from RESULTS_SUMMARY.md / PRESENTATION_NOTES.md / figures_overview.pdf.
- **HLA-C**: naive classifier validated as sufficient. Phase 2 uses the standard (unflipped) classifier for HLA-C, results presented normally.
