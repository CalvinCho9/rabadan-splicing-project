# Phase 5 — pan-cancer matched tumor-vs-normal, using `gdc_sample_sheet_normal_with_hla.tsv`

Generated by `scripts/phase5_pancancer_matched_normal.py`, in direct response to Anqi's guidance: 106 BRCA normals is enough for a proportion comparison (Phase 2 already does this), and what would most strengthen the pan-cancer pass is resolving which cancer type each pooled `NORMAL` sample actually came from, not adding more BRCA normals. The new sheet (740 normal samples, 24 TCGA projects, with HLA-A/B/C typing) does exactly that: every pooled-`NORMAL` barcode in the pan-cancer SJ files resolves to a real TCGA project (145/145 for the HLA-A file, 318/318 for HLA-B/C — 0 unresolved).

This turns `scripts/phase3_pancancer_descriptive.py`'s explicitly-descriptive pooled-NORMAL comparison into a real, matched-cohort tumor-vs-normal *test* — same Fisher-exact/Wilson-CI/odds-ratio machinery as the BRCA headline test — for every cohort where the resolved normal count and the existing tumor count both reach 3+ samples. Every other pan-cancer cohort (no resolvable normal at all, e.g. TCGA-LGG/TCGA-ACC — not among the sheet's 24 projects — or too few samples on one side, e.g. TCGA-THCA's 47 normal vs 1 tumor, TCGA-UCEC's 79 tumor vs 1 normal) is left exactly as Phase 3 treats it: descriptive context only.

## Quarantine

Same rule as every other phase: HLA-B's classifier verdict from Phase 1 is untrustworthy. ALL HLA-B Phase 5 output is written under `outputs/UNVALIDATED_HLA_B_phase5_*` and excluded below and from every presented document.

## Constitutive-artifact exclusion

Two layers, applied BEFORE the headline test. (1) HLA-A\*11:01 — already established project-wide as a constitutive, non-tumor-associated artifact (Finding 3/5) — is excluded unconditionally in every cohort, regardless of its carrier count there. This was NOT the first version of this script: an initial pass re-derived the exclusion per cohort the same way Phase 2 does for BRCA (`hla_common.top_event_penetrance` + `add_verdict`, which requires 10-20+ carriers before flagging anything), and that missed A\*11:01 in TCGA-CHOL/TCGA-HNSC because only 2-3 tumor samples carry it in either cohort — caught by inspecting the per-pattern detail table before writing up results: 100% of HLA-A TCGA-CHOL's and TCGA-HNSC's *original* intron5_retention carriers turned out to be A\*11:01's known artifact pattern, not new biology. (2) The Phase-2-style per-cohort re-derivation still runs on top, to catch a *different* constitutive allele these new cohorts might reveal that BRCA never had — none did here (HLA-C's recurring alleles below, `hla_c_03_03`/`hla_c_03_04`, are the real_variable_splicing_candidate from Finding 4, correctly left in, not excluded). Excluded allele(s) per pair are in `table_phase5_cohort_meta.csv`.

## Bonus: HLA-C's Finding-4 candidate corroborates across independent cohorts

`1273_1711->1291_1711` (alleles `hla_c_03_03`/`hla_c_03_04` — closely related sub-alleles at the same locus showing the same junction, plausible given how similar their sequences are) was flagged in Finding 4 as HLA-C's one real_variable_splicing_candidate in BRCA, not an artifact (unlike A\*11:01): present in tumor, essentially absent in normal, but resting on a fragile n=1 normal-side carrier there. This is the *opposite* situation from A\*11:01 — cross-cohort corroboration here would strengthen a real candidate rather than just confirm an artifact is universal, so it's worth checking the same way Finding 5 checked A\*11:01:

| Cohort | Tumor carriers | Normal carriers |
|---|---|---|
| TCGA-BRCA (Finding 4) | 34 | 2 |
| TCGA-CHOL | 1 | 0 |
| TCGA-HNSC | 4 | 0 |
| TCGA-KIRC | 3 | 0 |

Pooled across BRCA + the 3 newly-matched cohorts: **42 tumor carriers vs 2 normal carrier(s)** (counts are per-allele-row sums, so a sample compound heterozygous for both 03:03 and 03:04 would be counted twice — negligible at these allele frequencies, but noted rather than presented as an exact distinct-patient count). The pattern is enriched in tumor in **every** cohort tested so far, never observed in any of the 80 non-BRCA normal samples carrying either allele (8 CHOL + 35 HNSC + 37 KIRC) — directionally consistent, but still **not** a replication: none of the individual cohort tests reaches significance (all Fisher p>0.5 above), and this cross-cohort view was not a pre-registered test either, so treat it as 'worth a dedicated follow-up with more normals specifically for this allele,' not as confirmed real variable splicing.

**Multiple testing:** 16 (gene, cohort, event class) headline tests run this phase; 0 have an OR 95% CI excluding 1 at the nominal (uncorrected) level. None of these were planned as a single pre-registered comparison — treat any nominal hit here the same way `docs/RESULTS_SUMMARY.md` treats the BRCA headline numbers: as one candidate among several tests, not FDR-corrected across cohorts, worth a closer look but not a standalone claim.
