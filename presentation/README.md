# Optional presentation figures

[Back to project overview](../README.md)

Individual research figures and tables are available in the [results index](../outputs/README.md).

The presentation-only `background_method.pdf` and `figures_overview.pdf` are not included in the repository. To regenerate them, run these optional commands from the repository root:

```bash
python scripts/make_figures_overview.py
python scripts/make_background_figures.py
```
